\begin{abstract}
This companion to the main report is a first person postmortem of the problems met
while building the compiler and how they were resolved, grouped by theme. It is
drawn from the engineering log kept from the first phase. The intent is to record
the real friction, the environment mismatches, the ODS surprises, and the one
genuine correctness bug, so that the reasoning behind the fixes is not lost.
\end{abstract}
